# Font Awesome Free SVG icons

This directory contains an unmodified subset of **Font Awesome Free 6.7.2**,
by Fonticons, Inc. / https://fontawesome.com.

Source: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/solid
SVG license: **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/
Upstream licensing and attribution details are preserved in LICENSE.txt and in
all SVG comments. These assets retain their upstream license independently of
the Wallpaper Studio source-code license.

The renderer uses the original SVG alpha shape with the current GTK CSS color;
the source files are not modified. The installer copies this directory with the
Python package, so runtime rendering works offline with no font installation.

To extend the collection, copy a Free solid SVG from that release into solid/,
keep its attribution comment, and restart the app. The catalog discovers SVG
filenames automatically. Use lowercase hyphen-separated names. Include only
assets whose license permits redistribution; this directory does not contain
Font Awesome Pro assets.
